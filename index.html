01 Why Wrenna

Zero to live in seconds

No npm install. No build servers. No configuration files. Paste your code and watch it render instantly.

Runs where you are

Built for low-spec hardware and mobile phones. If it can run a browser, it can run Wrenna. No GPU-hungry effects.

Your code, your browser

Everything runs locally in your browser. No uploads to unknown servers. No accounts required. Your code never leaves your device.
